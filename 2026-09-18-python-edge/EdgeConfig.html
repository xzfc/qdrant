EdgeConfig

qdrant_edge.EdgeConfig 

EdgeConfig(
    vectors: (
        EdgeVectorParams
        | dict[str, EdgeVectorParams]
        | None
    ) = None,
    sparse_vectors: (
        dict[str, EdgeSparseVectorParams] | None
    ) = None,
    on_disk_payload: bool | None = None,
    hnsw_config: HnswIndexConfig | None = None,
    quantization_config: (
        QuantizationConfigType | None
    ) = None,
    optimizers: EdgeOptimizersConfig | None = None,
    max_search_threads: int | None = None,
    search_pool_core: int | None = None,
)

Configuration for creating a new Qdrant Edge shard.

Parameters left as None are "not specified": when loading an existing shard each one resolves through provided -> persisted -> derived from segments -> default, so an unspecified parameter keeps the shard as it is. vectors and sparse_vectors define the stored data: if provided they are validated for compatibility against the existing segments, if omitted they are inherited from the shard.

Parameters:

Name Type Description Default
vectors EdgeVectorParams | dict[str, EdgeVectorParams] | None

Dense vector configuration. Can be a single EdgeVectorParams for the default vector (name "") or a dict of name -> EdgeVectorParams. Optional if sparse_vectors is provided (sparse-only config).

 None
sparse_vectors dict[str, EdgeSparseVectorParams] | None

Optional sparse vector configurations.

 None
on_disk_payload bool | None

If True, store payload on disk (mmap); otherwise in RAM. None keeps the shard's current value (defaults to on-disk).

 None
hnsw_config HnswIndexConfig | None

Optional global HNSW config (used when building HNSW index).

 None
quantization_config QuantizationConfigType | None

Optional global quantization config.

 None
optimizers EdgeOptimizersConfig | None

Optional optimizer settings.

 None
max_search_threads int | None

Number of threads in the shard's search thread pool, which runs per-segment reads in parallel and loads segments in parallel. None (the default) derives the count from the number of CPUs, matching the core search runtime.

 None
search_pool_core int | None

Pin every search pool thread to this CPU core (best-effort), bounding search compute to one core. None = OS scheduling.

 None
